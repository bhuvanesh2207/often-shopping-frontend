# 🛒 E-Commerce Frontend  

## 🚀 Overview  
This project is the **Frontend for the E-Commerce System**, built using **React.js**.  
It provides a clean and responsive **user interface** for Admins, Customers, and Delivery Personnel to interact with the backend services.  

The frontend communicates with the backend (Spring Boot microservices) through RESTful APIs and ensures a smooth shopping experience with modern UI/UX practices.  

---

## 👥 User Roles and Responsibilities  

| Role            | Frontend Features                                                                 |
|-----------------|----------------------------------------------------------------------------------|
| **Admin**       | Dashboard access, product management forms, order tracking UI                   |
| **Customer**    | Product browsing, cart management, checkout flow, and order history             |
| **Delivery**    | Delivery dashboard, update order status, and manage assigned deliveries         |

---

## 💻 Tech Stack  

- **React.js 18** (Frontend framework)  
- **JavaScript (ES6+)** (Core programming language)  
- **Axios** (API communication with backend)  
- **React Router DOM** (Navigation & routing)  
- **HTML5 & CSS3** (UI structure & styling, no Bootstrap/Tailwind)  

---

## 🔑 Key Features  

- ✅ **Responsive UI** (Custom HTML + CSS styling)  
- ✅ **Role-based dashboards** (Admin, Customer, Delivery)  
- ✅ **Product catalog display with filters & search**  
- ✅ **Shopping cart & checkout flow**  
- ✅ **Order tracking & delivery status updates**  
- ✅ **Integration with backend REST APIs**  
- ✅ **Reusable React components**

## 🚀 Quick Start  

```bash
# Clone the repository
git clone https://github.com/yourusername/OftenShopping-Frontend.git
cd OftenShopping-Frontend

# Install dependencies
npm install
# or
yarn install

# Start the development server
npm start
```
